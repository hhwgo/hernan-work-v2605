# Hernán H. Landing Page

Landing page personal de Hernán H., destacando su primer día en Caja 18 de Septiembre y asistencia a eventos como V21 Open Fest y Chile Fintech Forum 2026.

## Características principales
- **Diseño responsivo**: Layout global con tema oscuro y acentos en azul esmeralda (#00d4c0).
- **Tarjetas temáticas**:
  - Caja 18 de Septiembre: Blanco y azul bandera chilena (#003DA5), con rojo (#D52B1E) en bordes.
  - V21 Open Fest: Negro (#0a0a0a) con verde pistacho (#93c572).
  - Chile Fintech Forum 2026: Mantiene tema global.
- **Tecnologías**: HTML5, CSS (custom properties), Vanilla JS. Fuentes: Inter y JetBrains Mono.

## Cómo usar
Abre `index.html` en cualquier navegador web moderno. No requiere servidor ni dependencias externas.

## Despliegue
Sube los archivos a cualquier hosting estático (GitHub Pages, Netlify, etc.). El archivo `CNAME` está configurado para dominio personalizado si es necesario.
